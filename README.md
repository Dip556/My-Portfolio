A modern, animated personal portfolio website built with **pure Vanilla HTML, CSS & JavaScript**. Features immersive dark space theme, custom interactions, and smooth animations.

![Portfolio Preview](https://via.placeholder.com/1200x600/000c1e/667eea?text=Portfolio+Preview)
> *Replace with actual screenshot for better visual appeal.*

## ✨ Features
- **Custom Cursor** & mouse-following gradients
- **Smooth Scrolling** & scroll-triggered animations (Intersection Observer)
- **3D Hover Effects** on project cards
- **Fully Responsive** (Mobile-first design)
- **Glassmorphism** navbar with backdrop blur
- **Video Backgrounds** in project demos
- **Contact Form** (frontend only)
- **Performance Optimized** (no frameworks, lightweight)

## 🚀 Quick Start
1. **Local Preview** (No setup needed):
   ```bash
   # Windows
   start index.html
   
   # macOS
   open index.html
   
   # Or drag index.html to your browser
   ```
2. **Deploy** (Free & Instant):
   - [Netlify](https://netlify.com): Drag/drop folder
   - [Vercel](https://vercel.com): `npx vercel`
   - [GitHub Pages](https://pages.github.com): Push to repo + enable Pages
